# Vertex

Учебный HTML/CSS-проект небольшого каталога компьютерной периферии.

## Структура

- `index.html` — главная страница;
- `catalog.html` — каталог;
- `contacts.html` — контакты;
- `css/style.css` — общие стили;
- `js/main.js` — минимальная работа модального окна и формы;
- `images/` — фотографии товаров.

## Технологии

HTML5, CSS3, минимальный JavaScript. Подключены шрифты Google Fonts: Bricolage Grotesque и Space Grotesk.
